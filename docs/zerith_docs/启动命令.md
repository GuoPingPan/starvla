## 0. 一次性环境准备

```bash
# 0.1 清理旧软链（train.sh 段1 会自动重建；若 ~/code ~/data 是真实目录请勿执行）
rm -rf ~/code ~/data

# 0.2 进入代码目录
cd /root/workspace/starvla

# 0.3a 阿里云 OSS 凭证（阿里云机器用；推荐写入 /root/.ossenv 让脚本自动 source，勿入库）
cat > /root/.ossenv <<'EOF'
export OSS_ACCESS_KEY_ID=<你的阿里云AK>
export OSS_ACCESS_KEY_SECRET=<你的阿里云SK>
export OSS_ENDPOINT=https://oss-cn-beijing.aliyuncs.com   # 华北2
export OSS_BUCKET=algo-public0
export OSS_NAMESPACE=orion
EOF
chmod 600 /root/.ossenv

# 0.3b 百度云 BOS 凭证（百度云机器用；也可写入 /root/.bosenv 让脚本自动 source）
export BOS_ACCESS_KEY_ID="YOUR_BOS_ACCESS_KEY_ID"
export BOS_SECRET_ACCESS_KEY="YOUR_BOS_SECRET_ACCESS_KEY"

# 0.4 SwanLab（在线模式需要；或命令末尾加 --local 免登录）
export SWANLAB_API_KEY="YOUR_SWANLAB_API_KEY"

# 0.5 代理：已在 ~/.bashrc 永久修复（http_proxy=64500，清除 7897）
#     ✅ 新终端无需再写 env -u HTTP_PROXY ...
```

## 4. 常用参数说明

| 环境变量 | 默认值 | 作用 |
| --- | --- | --- |
| `BATCH` | 10 | 单卡 batch size（`per_device_batch_size`） |
| `MAX_STEPS` | 20000 | 总训练步数（`max_train_steps`） |
| `SAVE_EVERY` | 5000 | checkpoint 保存间隔（`save_interval`） |
| `UPLOAD_DIR` | `bos://umi-gripper/Orion/ckpts/<RUN_ID>/` | 段6 上传目标 |
| `NUM_GPUS` | 全部 GPU | 单机使用的卡数 |
| `NUM_MACHINES` / `MACHINE_RANK` / `MAIN_PROCESS_IP` | 1 / 0 / 空 | 多机分布式（>1 启用） |
| `--local` | 在线模式 | SwanLab 本地模式（免登录） |

> 注意：这些环境变量会**覆盖 yaml 里的同名配置**（如 yaml `max_train_steps: 10000` 会被 `MAX_STEPS=20000` 覆盖）。

## 5. 分布式训练（多机）

每台节点跑同一条命令，各自设置节点序号：

```bash
# 主节点（node 0）
NUM_MACHINES=2 MACHINE_RANK=0 MAIN_PROCESS_IP=<主节点IP> BATCH=2 \
  bash scripts/train.sh \
    examples/realRobots/zerith_pi05/train_files/run_umi_shenzhen_relative_6d_v2.yaml \
    c06b17c0afaf6cdc800f339b2d26c34802ed7586

# 从节点（node 1）
NUM_MACHINES=2 MACHINE_RANK=1 MAIN_PROCESS_IP=<主节点IP> BATCH=2 \
  bash scripts/train.sh \
    examples/realRobots/zerith_pi05/train_files/run_umi_shenzhen_relative_6d_v2.yaml \
    c06b17c0afaf6cdc800f339b2d26c34802ed7586
```

> SLURM 集群：`MACHINE_RANK` 自动取 `$SLURM_NODEID`，`MAIN_PROCESS_IP` 自动取 `$MASTER_ADDR`，无需手动设。
